# half-it

ダーツのゲーム「ハーフイット」を一人で遊ぶためのスコアカウンター。
ブラウザだけで動くペラいち（単一ページ）の静的サイト。

公開 URL: https://fukayahiroki.github.io/half-it/

## ハーフイットとは

決められた場所を狙って投げていくダーツのゲーム。
狙った場所に入れば得点が増えるが、1 ラウンドで 1 投も入らないと持ち点が半分になる。
このサイトは、その持ち点の増減を自動で計算してくれるカウンター。

## 遊び方

- 持ち点 **40** からスタートする。
- 全 **9 ラウンド**、1 ラウンドで **3 投**する。
- ラウンドごとに狙う場所が決まっている。

### ラウンドと狙う場所

| R | 狙う場所 | R | 狙う場所 | R | 狙う場所 |
|---|---|---|---|---|---|
| 1 | 15 | 4 | 17 | 7 | 19 |
| 2 | 16 | 5 | 18 | 8 | 20 |
| 3 | DOUBLE | 6 | TRIPLE | 9 | BULL |

### 得点と半減

- 1 投でも入れば、そのラウンドの得点を持ち点に**加点**する。
- 3 投すべて外すと、持ち点が**半減**する（小数は切り捨て）。
- 9 ラウンド終了時の持ち点が最終スコア。半減した回数もあわせて表示される。

## 画面の使い方

画面上部に「持ち点」「今のラウンド」「狙う場所」が表示される。
そのラウンドの結果を入力すると、持ち点が計算されて次のラウンドに進む。

### 3 点メニュー

画面右上の `⋮` を押すと、表示に関する設定が開く。パネル外をクリックするか `Esc` で閉じる。

- **手入力で入力する** … 入力方式を「マーク数」と「手入力」で切り替えるスイッチ（ON で手入力）。
- **シンプルモード** … 入力に必要ないものを隠して画面を広く使い、
  「持ち点」「ラウンド」「狙う場所」を大きく表示する。
  隠れるのはタイトル・説明文・入力方式のラジオボタン・マーク数の説明文。
  入力方式はメニューのスイッチから切り替えられる。
- **黒基調にする / 白基調にする** … 画面の色を切り替えるボタン。
  最初は端末の設定に合わせて表示され、押すともう一方の配色になる。

### 入力方式

「マーク数」と「手入力」の 2 つから選べる。
入力エリアのラジオボタンと、3 点メニューのスイッチのどちらからでも切り替えられる。
どちらも同じ設定を指すので、表示は常に一致する。

**マーク数**

入ったマーク数のボタンを押すだけ。`0` はミス（半減）。

| ラウンド | 選べるマーク数 | 加点 |
|---|---|---|
| 数字（15〜20） | 0〜9 マーク | マーク数 × その数字 |
| BULL | 0〜6 マーク | マーク数 × 25 |

**手入力**

そのラウンドの合計得点を入力する。
DOUBLE / TRIPLE のラウンドはマーク数だけでは得点が決まらないため、
入力方式に関係なく**手入力のみ**になる。

| ラウンド | 入力できる範囲 | 単位 |
|---|---|---|
| 数字（15〜20） | 0 〜 その数字 × 9 | その数字の倍数 |
| DOUBLE | 0 〜 150 | 2 の倍数 |
| TRIPLE | 0 〜 180 | 3 の倍数 |
| BULL | 0 〜 150 | 25 の倍数 |

DOUBLE のラウンドはインブル（50 点）もダブル判定になるため、
1 投の最高は D20 の 40 点ではなく 50 点で、3 投すべてインブルの **150 点**が最高得点。

範囲や単位に合わない値を入力すると、エラーメッセージが表示される。

### キーボード操作

| キー | 動き |
|---|---|
| `0`〜`9` | そのマーク数を確定する（`0` はミス。マーク数で入力するときだけ） |
| `B` | 1つ戻る |
| `S` | 最初から |
| `Esc` | 3 点メニューを閉じる |

`B` と `S` はゲーム終了後にも使える。
`Cmd` / `Ctrl` / `Alt` と一緒に押したときはブラウザの操作を優先するので、`Cmd + S` などは今までどおり。

3 点メニューを開いている間と、手入力の欄に入力している間は、
誤って持ち点が動かないようにこれらのキー操作を受け付けない。

### やり直しとスコア表

- **1つ戻る** … 直前のラウンドの入力を取り消す（`B` キーでも押せる）。
- **最初から** … 持ち点 40 の状態にリセットする（`S` キーでも押せる）。
  確認なしでその場でリセットされ、消えた記録は戻せない。
- **スコア表** … 各ラウンドの「狙う場所」「結果」「加点/半減」「持ち点」が一覧で残る。
  初期状態は閉じているので、見るときは「スコア表」を押して開く。

## 注意点

- スコアを保存する機能はないため、ページを再読み込みすると記録は消える。
- 3 点メニューの設定（入力方式・シンプルモード・画面の色）も保存しないので、
  再読み込みすると初期状態（マーク数・シンプルモード OFF・端末の設定どおりの配色）に戻る。

## 技術情報

### 構成

素の HTML / CSS / JavaScript のみで構成しており、ビルドツールや依存ライブラリは使わない。

### ディレクトリ構成

```
half-it/
├── index.html      # ページ本体
├── css/style.css   # スタイル
├── js/main.js      # スクリプト
└── .nojekyll       # Jekyll のビルドを無効化し、ファイルをそのまま配信する
```

### ローカルでの確認

`index.html` をブラウザで直接開けば表示できる。

```sh
open index.html
```

相対パスも含めて本番に近い形で確認したい場合はローカルサーバーを立てる。

```sh
python3 -m http.server 8000
# http://localhost:8000/ を開く
```

### 公開設定（GitHub Pages）

GitHub の Settings → Pages で `Deploy from a branch` / `main` / `/ (root)` を指定している。
